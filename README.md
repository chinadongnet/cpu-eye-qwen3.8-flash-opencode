# CPU Eye — C++ → 汇编 指令级动态模拟器

纯前端（零依赖）CPU 模拟器：把 C++ 子集编译成 **x86 (IA-32) / x86-64 (System V) / ARM32 (AAPCS) / ARM64 (AAPCS64)** 四种架构的汇编，逐指令执行，动态展示寄存器、标志位、栈帧变量、内存（字节级高亮本步变化）、程序输出与当前源码行。

**在线演示**: https://chinadongnet.github.io/cpu-eye-qwen3.8-flash-opencode/

## 运行 / 部署

任意静态服务器即可（无构建步骤）：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765
```

## 使用

1. 顶部切换 CPU 模型（自动重新编译当前代码）。
2. 左侧选择内置示例或直接编辑 C++ 代码，点 **编译**。
3. **▶ 运行 / ⏭ 单步 / ⏮ 回退 / ⏹ 重置**，速度可调。
4. 内置示例带期望值（输出、返回值、对象成员内存）；程序退出后自动 **✓ 验证**。

内置示例：class 对象成员读写（必备样例 `class A{int x;int y;}`）、for 累加、递归阶乘（验证栈帧/调用约定）、双对象成员交换、while 辗转相除、迭代斐波那契。

## 支持的 C++ 子集

`class`（public/private 整型成员）、全局/局部整型变量、赋值与复合赋值、`+ - * / %`、一元 `-`、`++ --`、比较与 `if/else`、`while`、`for`、`break/continue`、函数定义与调用（含递归、多参数按各架构真实 ABI 传参）、`cout <<` 整型与字符串、`return`。

## 实现要点

- `js/compiler.js` 词法/语法 → 平台无关 MIR（双累加器 A/B + 栈帧槽位模型）。
- `js/{x86,x64,arm32,arm64}.js` MIR → 各架构真实风格指令（push/pop、leave、stp/ldp 写回、b.cond、sdiv/msub、cdq/cqo 符号扩展除法等），并带对应解释器与快照（支持回退/快进回放）。
- `js/cpuview.js` **CPU 结构示意图**（SVG）：PC、指令存储器窗口（地址→指令，当前行高亮）、CU 控制单元、IR 指令寄存器（译码）、ALU（运算数/结果/操作）、MEM 的 MAR/MDR（访存地址/数据/读写方向）、分支目标、标志位、寄存器组——每执行一步按真实数据点亮相应部件与数据通路（取指→译码→执行→访存→写回）。
- 帧布局：`ebp/rbp/r11/x29` 为基址，成员访问 = `[基址+槽位偏移]`；main 序言结束时捕获对象内存用于验证。
- 栈顶固定 `0xFFF0`，64 KB 内存窗口用于演示。
- 测试：`node test/run.js`（6 示例 × 4 架构 = 24 用例全通过）；`node test/dom.js`（UI 冒烟：单步/回退/切换架构/验证）。

## 已知简化

32 位整型语义（64 位架构同样以 w/e* 寄存器演示）；有符号比较忽略 OF（CMP 仅置 Z/N）；`out/outstr` 为演示用伪指令（对应真实 syscall）；不支持指针、数组、引用、构造函数。
